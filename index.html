What SHAP shows, and what it does not

A boosted tree model is fitted to the target, and SHAP values divide each respondent's prediction among the features that went into the model. The mean absolute SHAP value of a feature is how much, on average, it moves the model's predictions. SHAP interaction values split that further into pairs of features whose contributions depend on each other.

  • SHAP describes how this fitted model uses each feature. It does not measure causal effects, and it describes the data only as well as the model fits it; the holdout R² reports that fit.
  • Correlated features share credit. Party and ideology, for example, can split importance between them, and the split can shift from one fit to the next. Repeated runs with different random seeds show how stable each ranking is.
  • A feature with large SHAP importance that is not in the respondent model is a candidate missing factor. Fitting the target on the model's residuals asks the same question directly: which features explain what the regression leaves over.
  • A large interaction value marks a pair worth testing. An interaction term in the regression (the Interaction tab) gives a coefficient, a standard error and a test; SHAP gives none of these.
  • SHAP values are in the units of the target and are not regression coefficients. Tree settings, the holdout split and the seed all change the results somewhat.
